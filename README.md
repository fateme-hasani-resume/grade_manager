
# Student Grade Manager

## Description
A beginner-friendly Python program that collects
student grades, stores them in a list, and calculates
the average grade.

## Features
- Student name input
- Collects three grades
- Stores grades in a Python list
- Calculates average grade
- Displays student information

## Concepts Learned
- Python Lists
- List indexing
- append() method
- for loops
- sum() function
- len() function
- f-strings
- Float data type

## Example

Input:
Fateme
18
16
20

Output:
Student: Fateme
Grades: [18.0, 16.0, 20.0]
Average grade: 18.0

## How to Run

python grade_manager.py
